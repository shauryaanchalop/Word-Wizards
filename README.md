## 📖 About The Project

Word Wizards is the official First-Year Student Development Society of **Akhilesh Das Gupta Institute of Professional Studies (ADGIPS)**.

This website serves as the society's digital headquarters, featuring:

* **Audition Results & Selected Members Portal** (187 Members with Search, Branch & Section Filters, and Sorting)
* **Catch-Up Auditions Showcase** (Highlighted Coming Soon Banner & Vintage Poster)
* **Council Generations** (Interactive Council 3.0, Council 2.0, and Council 1.0 Portfolios)
* **Society Vision & Departments**
* **Event Archives & Multimedia Galleries**
* **Faculty Mentors & Advisory Board**

The platform is engineered with a glassmorphism design system, custom GSAP micro-animations, Lenis smooth scrolling, and device compatibility across phones, touchscreen laptops, and PCs.

## 🚀 Key Features

### 🎓 Selected Members & Audition Results Portal
* **187 Selected Members**: Complete official roster of inducted students with Branch and Section badges.
* **Instant Name-Only Search**: Clean, real-time search field filtered strictly by student name.
* **Branch Filter Dropdown**: Filter students across all engineering branches (AIDS, AIML, CS, CSE, CST, ECE, IT, ME).
* **Section Filter Dropdown**: Filter across sections (Section A through W, Section G&H).
* **Dual-Mode Sorting**: Sort results by Branch (A → Z / Z → A) and Section (A → Z / Z → A).
* **One-Click Reset**: Instant reset button returning filters and search to default state.
* **Dynamic Count & Empty State**: Live counter badge reflecting filtered count, with contextual search assistance when no match is found.
* **Audition Results Live Popup**: Modal alert welcoming freshers and directing them directly to the results directory.

### 🎪 Event Showcases & Catch-Up Auditions
* **Highlighted Catch-Up Auditions Banner**: Positioned directly above the Council switcher in the Events tab.
* **Balanced Vertical Layout**: Cohesive side-by-side spread on laptop and desktop screens matching text content with poster height.
* **Vintage Wizarding Poster**: Cloudinary-hosted high-resolution poster artwork.
* **Event Archives**: Phase-wise archives covering Science Project Exhibition, JAM Sessions, Inductions, and Escape Room challenges across Council 3.0, 2.0, and 1.0.

### 👥 Council Profiles & Squircle Modal
* **3D Tilt Cards**: Interactive hover cards powered by GSAP perspective transformations on desktop.
* **Scrollbar-Free Modal Card**: Card modal spreads content evenly in the available viewport without scrollbars.
* **1:1 Aspect Ratio Avatars**: Profile photos rendered in a 1:1 squircle format with ambient glow, preventing clipping or distortion.
* **Direct Social Links**: Integrated Instagram and LinkedIn icons for core leadership members.

### 📱 Universal Device & Touchscreen Compatibility
* **Dynamic Pointer Cursor**: Prevents mouse disappearance on touchscreen laptops (Surface, 2-in-1, HP/Dell touch) by dynamically enabling the GSAP glowing cursor only when active mouse/trackpad movement is detected.
* **Mobile-First Responsiveness**: Tailored layouts for small screens down to 360px and mobile landscape orientations.
* **Lenis Smooth Scroll**: GPU-accelerated smooth scrolling on desktop synced with ScrollTrigger and reveal animations.
* **Keyboard Accessibility**: Global `Escape` key listeners to dismiss modals, popups, and image lightboxes.

## 🛠 Tech Stack

* **Core**: Semantic HTML5, CSS3, Vanilla Modern JavaScript (ES6+)
* **Animation & Motion**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform) + [ScrollTrigger](https://greensock.com/scrolltrigger/)
* **Smooth Scrolling**: [Studio Freight Lenis](https://lenis.studiofreight.com/)
* **Typography**: Google Fonts (*Cinzel Decorative*, *Playfair Display*, *Poppins*, *Montserrat*)
* **Media Optimization**: Cloudinary CDN (responsive image & reel streaming)

## ⚙️ Local Development

### 1. Clone Repository
```bash
git clone https://github.com/shauryaanchalop/word-wizards.git
```

### 2. Navigate to Project
```bash
cd word-wizards
```

### 3. Run Locally
Run using any static file server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
Or open `index.html` directly in your preferred web browser.
